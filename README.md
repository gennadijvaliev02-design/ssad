# Сады Валиевых — Atelier Edition

Независимая дизайнерская переработка сайта «Сады Валиевых» (на основе репозитория `gennadijvaliev02-design/sad`). **Исходный GitHub-репозиторий не изменён.**

## Запуск

1. Распакуйте ZIP-архив.
2. Откройте `index.html` в браузере.
3. Для публикации загрузите `index.html`, `styles.css`, `app.js` в корень нового репозитория GitHub Pages или на VPS.

Сайт статический и не требует Node.js, сборки, npm, Tailwind или сервера. Каталог, фильтры, мобильное меню, выбор сорта/веса/доставки и формирование текста заказа работают на JavaScript.

## Важное об изображениях

Для честного сравнения и сохранения фотографий из исходного сайта **изображения загружаются по абсолютным HTTPS-ссылкам из вашего публичного GitHub-репозитория `sad`**. В ZIP бинарные изображения не копировались. Для полноценного отображения фотографий при открытии сайта необходим интернет и доступ к GitHub Raw. Если перенесёте сайт на постоянный домен, рекомендуем скачать оригинальные `assets/images` в новый проект и заменить абсолютные ссылки относительными.

Не все фотографии в исходном репозитории являются реальными кадрами из сада. Реальные фото отмечены в исходном `SOURCES.md`; часть картинок — иллюстрации сортов из Wikimedia. Новый дизайн не выдаёт их за собственные фото урожая.

## Дизайн и доступность

Направление: organic editorial / семейное фермерское ателье. Типографика Cormorant Garamond + Golos Text (с поддержкой кириллицы), тёмная хвоя и кремовый фон, асимметричные блоки, цветовые акценты меди. Своя CSS-система без фреймворка.

Есть адаптивная сетка, клавиатурная навигация, aria-атрибуты, focus-состояния, `prefers-reduced-motion`, lazy-loading каталога, alt-тексты и мобильная CTA-панель.

## Использованные принципы Skills

Применены идеи из `frontend-design` (осознанный художественный стиль, типографика, композиция, движение и практичность), с опорой на доступность и семантику. Эти файлы не содержат установленных сторонних Skills и не требуют их для работы.

## Контроль исходных сведений

Оригинал: https://github.com/gennadijvaliev02-design/sad

Изображения и лицензии: https://github.com/gennadijvaliev02-design/sad/blob/main/SOURCES.md

В папке `assets/illustrations` лежат **четыре собственные SVG-иллюстрации**, которые автоматически служат фоном, если фотографии из GitHub недоступны. Это иллюстрации, а не фотографии реальных плодов/деревьев; при доступных внешних фото они скрыты под ними. Поэтому даже офлайн сайт не выглядит пустым.

## Видео

Сохранён видеоблок с оригинальным `assets/videos/hand-selection.mp4`, который загружается с исходного GitHub по запросу (`preload="none"`). Если видео заблокировано на сети посетителя, оно может не воспроизводиться; для полностью автономного деплоя скачайте оригинальное видео в проект и поменяйте URL в `index.html` на локальный.
